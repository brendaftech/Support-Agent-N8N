<h1 align="left">❓ O que é o projeto?</h1>

###

<h3 align="left">Este projeto consiste na utilização de um webhook criado na plataforma n8n, que funciona como uma porta de entrada para receber mensagens e iniciar automaticamente um fluxo de automação.<br>O link representa um endpoint que permite a comunicação entre o usuário e o sistema desenvolvido.</h3>

###

<h1 align="left">⚙️ Como funciona?</h1>

###

<h3 align="left">O funcionamento ocorre em etapas simples:<br><br>📩 O usuário envia uma mensagem para o link do webhook;<br>🌐 A requisição HTTP é recebida pelo sistema;<br>🔔 O webhook é acionado automaticamente;<br>⚙️ O n8n executa um fluxo de automação previamente configurado.</h3>

###

<h1 align="left">🤖 O que o sistema faz após receber a mensagem?</h1>

###

<h3 align="left">Após o recebimento, o sistema pode:<br><br>Processar o texto enviado;<br>Integrar com outras ferramentas externas;<br>Utilizar inteligência artificial para gerar respostas.</h3>

###

<h1 align="left">📊 Registro de dados</h1>

###

<h3 align="left">Todas as interações são registradas automaticamente em uma planilha do Google Sheets, incluindo:<br><br>-Mensagens enviadas;<br>-Número de identificação do usuário.<br><br>Isso permite organização, análise e acompanhamento do histórico de forma estruturada.</h3>

###

<h1 align="left">💬 Como o usuário recebe a resposta?</h1>

###

<h3 align="left">Após o processamento, o sistema retorna uma resposta automática ao usuário, funcionando como um chatbot.</h3>

###

<h1 align="left">🎯 Objetivo do projeto</h1>

###

<h3 align="left">O objetivo principal é criar um sistema automatizado que:<br><br>-Recebe e processa mensagens via webhook;<br>-Automatiza fluxos com o n8n;<br>-Armazena dados para análise;<br>-Retorna respostas de forma inteligente;<br>-Melhora a eficiência na comunicação e organização das informações.</h3>
